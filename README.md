# Personal Portfolio Website

This is my personal portfolio website, developed using React.js to showcase my background, technical skills, projects, education, and professional certifications as a Junior Web Developer.

The website features a modern and minimalist design with smooth animations, interactive components, and bilingual support (Indonesian and English).

## Built with

- React.js
- JavaScript
- Tailwind CSS
- React Router DOM
- Motion for React
- Lucide React
